🐛 发现并修复的缺陷
[严重] NODE_ENV 环境检测在浏览器中失效，导致生产环境默认授予 ADMIN 权限
原代码使用 typeof NODE_ENV !== 'undefined' 检测环境，但 NODE_ENV 是 Node.js 环境变量， 浏览器中永远为 undefined，导致条件始终为 false，生产环境也会默认返回 ADMIN 角色。 这是一个权限提升漏洞：任何访客在未登录状态下均可访问迁移报告页面并导出数据。
创建 src/app-config.js， 使用 location.hostname 检测环境（localhost/127.0.0.1/内网IP → development，其余 → production）， 开发环境默认 ADMIN，生产环境默认 GUEST。安全降级原则：无 location 上下文时默认 production。
⚙️ 环境与角色配置
配置项开发环境 (development)生产环境 (production)检测方式
环境检测 localhost, 127.0.0.1, 192.168.*, 10.*, 172.16-31.* 其余所有域名 location.hostname 正则匹配
默认角色 admin（方便调试） guest（安全默认） AppConfig.ENV 判断
迁移报告权限 默认可访问 需显式设置 admin 角色 PAGE_PERMISSIONS.migration = ADMIN
角色存储 localStorage.userRole try-catch 降级
无 localStorage 时 降级为 admin 降级为 guest catch 块回退到环境默认值
